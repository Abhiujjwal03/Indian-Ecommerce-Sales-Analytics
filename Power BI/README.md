# Power BI Dashboard – Indian E-Commerce Sales & Customer Analytics

## Project Overview
This Power BI dashboard provides insights into Indian e-commerce sales performance, customer behavior, product performance, and order distribution.

The dashboard uses data from 250,000 orders, 40,000 customers, and 2,000 products.

## Dashboard Pages

### 1. Sales Overview
This page provides an overview of sales performance through:
- Total Sales
- Total Orders
- Total Quantity Sold
- Average Order Value
- Monthly Sales Trend
- State-wise Sales Analysis
- Order Status Distribution

![Sales Overview](Sales_Overview.png)

### 2. Customer & Product Analysis
This page focuses on customer demographics and product performance through:
- Total Customers
- Total Products
- Average Customer Rating
- Total Product Categories
- Sales by Customer Age Group
- Product Category Sales Analysis
- Top 10 Best-Selling Products
- Customer Rating Distribution

![Customer & Product Analysis](Customer_Product_Analysis.png)

## Tools & Technologies
- Power BI Desktop
- DAX
- MySQL
- Data Visualization
- Data Analysis

## Key Business Rules
- Sales KPIs and sales performance charts include only Delivered orders.
- Order Status Distribution includes all order statuses.
- Customer and product KPIs represent distinct counts.
- Average Customer Rating excludes blank ratings.
